- GitHub Pages 배포 완료, 휴대폰 사파리에서 사용 중
- 「파일 저장」: zip 1개(한글 보고서 + 사진 폴더)로 저장되도록 수정됨
- 생성 HWPX는 구조 검사(tests/validate_hwpx.py) 통과. **한글 프로그램에서 실제로 연 결과는 담당자 확인 필요**

## 확인이 필요한 문제
1. **「메일로 보내기」가 담당자 아이폰에서 동작하지 않음**
   - 추정 원인: 사파리가 .hwpx(application/hwp+zip) 파일 공유를 거부(canShare=false)
   - 시도할 것: 보고서를 zip으로 감싸 공유 / 공유 전 canShare 결과를 화면에 표시해 원인 확정 / 사진(jpg)만 공유는 되는지 확인
2. 생성된 .hwpx를 한글에서 열었을 때 사진 크기·캡션·줄간격이 원본과 같은지 (담당자 확인 후 기록)

## 대상목록 기관 메일 전달 (2026-10-28 완료, 앱 버전 2026.10.28-E) — 지시서 2(서버 팀 칸)를 대체
- 팀장이 `dist/admin.html`(내부망·오프라인) 또는 `#admin`에서 암호화 목록 파일(.sajin) → 기관 메일 첨부 → 휴대폰 「목록 파일 불러오기」
- 운영 방법: `docs/대상목록_운영방법.md`

### 담당자 확인 필요
1. 저장소 이력 확인 결과 예전 목록 파일은 **올라간 적이 없어** 이력 정리·비밀번호 교체는 필요 없습니다. (확인만 부탁드립니다)
2. 기관 메일이 `.sajin` 같은 낯선 확장자 첨부를 막나요? → **확인 중** (막히면 관리 화면 「.txt 로 저장」 사용, 필요하면 기본값 변경)
   - 함께 확인: 휴대폰 사파리 웹메일에서 `.sajin` 첨부를 눌렀을 때 내려받아지는지(글자로 열리면 공유 → 「파일에 저장」)
3. 휴대폰 기관 메일 앱이 공유 창에 나타나나요? → **안 나타남. 사파리로 웹메일에 들어가 첨부** (2026-10-28 반영: 「파일 저장 (메일 첨부용)」을 주 버튼으로, 안내 문구를 웹메일 기준으로)
4. `admin.html`의 내부망 반입 → **가능할 것으로 보임** (실제 반입 후 더블클릭으로 열리는지 확인 필요)

## 담당자 요청 반영 (2026-10-28)
- **팀마다 비밀번호 따로** (1팀 비밀번호, 2팀 비밀번호 …): 관리 화면은 팀을 먼저 정하고 → 그 팀 비밀번호를 넣어야 목록 파일·QR을 만들 수 있음. 팀장이 아니어도 그 팀 비밀번호를 알면 누구나 만들 수 있음. 휴대폰은 여러 팀 키를 저장하고, 다른 팀 목록이면 그 팀 비밀번호를 물음
- **앱 이름 「현장 사진대지」 → 「사실관계조사」** (화면 제목·브라우저 탭·관리 파일·메일 본문·QR 인쇄물). 한글 보고서 양식 문구는 바꾸지 않음
