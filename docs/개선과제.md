# 개선 과제 및 현황

## 현재 상태 (2026-10-27)
- GitHub Pages 배포 완료, 휴대폰 사파리에서 사용 중
- 「파일 저장」: zip 1개(한글 보고서 + 사진 폴더)로 저장되도록 수정됨
- 생성 HWPX는 구조 검사(tests/validate_hwpx.py) 통과. **한글 프로그램에서 실제로 연 결과는 담당자 확인 필요**

## 확인이 필요한 문제
1. **「메일로 보내기」가 담당자 아이폰에서 동작하지 않음**
   - 추정 원인: 사파리가 .hwpx(application/hwp+zip) 파일 공유를 거부(canShare=false)
   - 시도할 것: 보고서를 zip으로 감싸 공유 / 공유 전 canShare 결과를 화면에 표시해 원인 확정 / 사진(jpg)만 공유는 되는지 확인
2. 생성된 .hwpx를 한글에서 열었을 때 사진 크기·캡션·줄간격이 원본과 같은지 (담당자 확인 후 기록)

## 개선 아이디어
- 점검 항목별 자주 쓰는 의견 문구(예: "대체로 적절하게 수행한 것으로 확인됨") 버튼
- 사진 촬영 시각(EXIF) 캡션 자동 표기 옵션
- 표지 부서명 입력 칸 (현재는 원본 양식 고정: 기반시설본부 시설안전평가실)
- 여러 보고서 보관(현재는 1건만 저장, "새로 시작" 시 삭제)
- 경영평가 실적용: 작성 건수·소요시간을 휴대폰에만 기록해 두었다가 담당자가 확인
