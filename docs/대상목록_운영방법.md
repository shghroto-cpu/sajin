# 대상목록 보내기 — 운영 방법 (담당자·팀장·실원용)

팀장이 대상목록 엑셀로 **목록 파일(.sajin)** 을 만들어 **기관 메일로 보내면**, 실원은 휴대폰 앱에서 그 파일을 불러와 바로 사진을 찍습니다.
팀원이 PC 앞에 모여 있으면 더 빠르게 **QR 코드**로 등록할 수도 있습니다 (아래 「QR로 등록하기」).

- 대상목록은 **기관 메일로만** 오갑니다. GitHub 같은 외부 서버에는 목록이 올라가지 않습니다.
- 목록 파일은 **팀 비밀번호로 암호화**되어 있어, 메일이 잘못 전달되거나 휴대폰을 잃어버려도 비밀번호 없이는 내용을 볼 수 없습니다.
- 사진·작성 내용은 지금처럼 **각자 휴대폰에만** 저장됩니다.
- 앱(빈 프로그램)만 GitHub Pages에 있고, 거기에는 기관 정보가 없습니다.

```
[팀장 PC (내부망)]                                  [실원 휴대폰]
엑셀 → admin.html 에서 목록 파일 만들기               사파리로 기관 웹메일 → 첨부파일 내려받기
  (대상목록_3팀부산권_26-4.sajin)                    → 앱 「목록 파일 불러오기」
→ 기관 메일에 첨부해 팀원에게 발송  ──기관 메일──▶     → 처음 한 번만 팀 비밀번호·내 이름 → 우리 팀 목록
```

---

## 처음 한 번 (담당자)

1. **관리 파일 `admin.html`을 내부망 PC로 반입**
   - `sajin-app` 폴더에서 `npm run build` 를 하면 `dist\admin.html` 이 만들어집니다 (Claude Code에 "관리 파일 만들어줘"라고 해도 됩니다).
   - 이 파일 하나만 있으면 **인터넷 없이** 더블클릭으로 열립니다 (Chrome·Edge). 외부로 아무것도 보내지 않습니다.
   - 망연계로 HTML 파일 반입이 막히면 **정보보안 담당자에게 반입 승인**을 요청하세요.
   - 반입이 안 되면, 인터넷 PC에서 `앱주소#admin` (예: `https://<아이디>.github.io/sajin/#admin`)을 열어도 같은 화면입니다.
2. **팀마다 비밀번호 정하기** (1팀 비밀번호, 2팀 비밀번호 …)
   - 12자 이상. 예) 단어 3~4개를 띄어쓰기 없이 이어 붙인 문장. **팀마다 다르게** 정합니다.
   - 그 팀 사람에게만 **구두나 내부 메신저로** 알려 주세요. **메일 본문에 절대 적지 마세요.**
   - 다른 팀 비밀번호로는 우리 팀 목록 파일·QR을 열 수 없습니다.
3. (Claude Code로 목록 파일을 만들 때만) **팀별 비밀번호 파일 만들기** — Claude Code에게 비밀번호를 말하지 마세요
   - 메모장 → 그 팀 비밀번호만 한 줄 입력 → 「다른 이름으로 저장」 → 위치: `sajin-app` 폴더, 파일 이름: `list-passphrase-<팀 이름>.txt`
     (팀 이름에서 띄어쓰기·괄호를 뺌. 예: 팀 이름 「1팀 (부산권)」 → `list-passphrase-1팀부산권.txt`)

## 출장 전 (팀장 또는 팀 비밀번호를 아는 팀원)

팀장이 아니어도 **그 팀 비밀번호를 아는 사람이면 누구나** 목록 파일·QR을 만들 수 있습니다.
엑셀 **출장자 열에 팀원 이름을 정확히** 적어 주세요. 휴대폰이 이 이름으로 우리 팀을 자동으로 구분합니다.

1. 내부망 PC에서 `admin.html` 더블클릭 (Chrome 또는 Edge)
2. **팀 이름**을 고르거나 새로 입력 (예: 1팀 (부산권)) → 「다음」 — 이 PC에서 쓴 팀 이름은 목록에서 고를 수 있습니다
3. **그 팀 비밀번호** 두 번 입력 → 「확인」 (처음 만드는 팀이면 여기서 정한 비밀번호가 그 팀 비밀번호가 됩니다)
   - 다른 팀 목록을 만들려면 「팀 바꾸기」 → 그 팀 비밀번호를 다시 입력
4. 「엑셀 선택」 → 미리보기 확인 (노란 칸은 읽지 못한 값)
   - **같은 목록을 고쳐 다시 보낼 때**: 「이전 목록 파일 불러오기」로 지난번 보낸 `.sajin`을 고르세요. 휴대폰에서 새 목록이 아니라 **갱신**으로 처리되어 사진·작성 내용이 그대로 남고, 바뀐 시설물이 표시됩니다.
5. 「목록 파일 만들기」 → `대상목록_팀이름_회차.sajin` 파일이 다운로드 폴더에 생깁니다
6. 기관 메일 새 메일 → 받는 사람: 팀원 → 이 파일 첨부 → 「메일 본문 복사」 내용을 붙여 넣기 → 발송
   - **비밀번호는 메일에 적지 않습니다.**
   - 기관 메일이 `.sajin` 첨부를 막으면: 「.txt 로 저장」에 체크하고 다시 만드세요.

**Claude Code로 만들 때 (담당자)**: `대상목록 파일 만들어줘: C:\Users\…\Desktop\3팀_대상목록.xlsx, 팀 이름 3팀(부산권)`
→ 미리보기 확인 후 엑셀과 같은 폴더에 `.sajin`이 생깁니다. (엑셀은 `sajin-app` 폴더 밖에 두세요)

## 출장 전 (실원, 휴대폰)

1. **사파리로 기관 웹메일**에 들어가 첨부파일(`대상목록_….sajin`)을 내려받습니다 → 「파일 앱 › 다운로드」에 저장됩니다
   - 파일 내용이 글자로 화면에 열리면: 아래 공유 버튼 → **「파일에 저장」**
2. 앱 주소를 **사파리·크롬**으로 열기 (카카오톡 안 브라우저 말고) → **「목록 파일 불러오기」** → 저장한 파일 선택
3. 처음이면 **우리 팀 비밀번호**와 **내 이름** 입력 → 우리 팀 목록이 보이면 완료
   - 다른 팀 목록을 받으면 「이 목록의 팀 비밀번호를 입력하세요」가 나옵니다 (그 팀 비밀번호를 알아야 열림). 한 번 넣은 팀 비밀번호는 다시 묻지 않습니다
   - 이름을 건너뛰면 「어느 팀 목록을 볼까요?」에서 팀을 고릅니다
   - 다른 팀 목록 파일도 불러오면 목록 맨 아래 「다른 팀 보기」에 들어갑니다
   - 같은 목록의 새 파일을 받으면 다시 불러오기만 하면 됩니다 (사진·작성 내용 유지, 더 오래된 파일은 무시)
- 오른쪽 위 「⋯」: 내 이름 바꾸기, 팀 다시 고르기, 보고서 받을 메일 주소, 불러온 목록 지우기, 팀 비밀번호 다시 입력

## QR로 등록하기 (팀원이 PC 앞에 있을 때)

QR 안의 목록도 **팀 비밀번호로 암호화**되어 있습니다. 목록은 PC 화면 → 휴대폰 카메라로만 옮겨지고, 메일·서버 어디에도 저장되지 않습니다.

**팀장 (출장 전)**
1. 내부망 PC에서 `admin.html` → 팀 이름 → 그 팀 비밀번호 → 엑셀 → **「QR 만들기」**
2. 팀원이 모여 있으면 화면의 QR을 각자 찍게 하기
   - QR이 여러 장이면 「다음 QR ▶」로 넘기거나 「한 화면에 모두 보기」
   - 출장계획(안)에 붙이려면 **「인쇄용 보기」** → 「인쇄」 (작게 붙이려면 「QR만 작게(4cm) 인쇄」)
   - 인쇄물에는 팀 이름·회차·만든 시각·사용 안내만 글자로 나오고, 시설물명·주소는 QR 안에만 (암호화) 들어갑니다
3. PC 앞에 없는 팀원에게는 지금처럼 「목록 파일 만들기」 → 기관 메일

**팀원 (휴대폰)**
1. 평소 쓰는 브라우저(사파리·크롬)로 앱을 열고 **「QR 찍기」** → 화면이나 종이의 QR 비추기 (기본 카메라 앱으로 찍어도 됩니다)
2. QR이 2장 이상이면 모두 찍기 — 순서는 상관없고, 「목록 QR 1 / 2 받음」으로 진행을 확인합니다
3. 처음이면 우리 팀 비밀번호·내 이름 입력 → 우리 팀 목록 확인

**주의**
- 기본 카메라로 찍었는데 목록이 안 보이면, 평소 쓰는 브라우저에서 앱을 열고 「QR 찍기」로 다시 찍으세요 (갤럭시 기본 카메라는 삼성 인터넷으로 열 수 있습니다. 그러면 앱이 「평소 쓰는 브라우저인가요?」라고 묻습니다)
- 시설이 많으면 QR이 여러 장이 됩니다 (10곳 이하 1장, 30곳 2장 정도). 4장이 넘으면 「QR에서 연락처·담당자 빼기」에 체크하거나 메일 파일 방식을 쓰세요
- QR 인쇄물은 암호화되어 있지만, 출장이 끝나면 일반 문서처럼 파기하세요

## 현장 이후
1. 보고서 **「파일 저장 (메일 첨부용)」** → 「파일 앱 › 다운로드」에 압축파일(보고서+사진)이 저장됩니다
   → **사파리로 기관 웹메일**에 들어가 새 메일 → 파일 첨부 → 「파일 앱 › 다운로드」에서 그 파일 선택 → 발송
   - 기관 메일 앱은 휴대폰 공유 창에 나타나지 않으므로 「공유」 버튼 대신 「파일 저장」을 쓰세요
   - 「⋯」에 보고서 받을 메일 주소를 넣어 두면, 저장 후 「받는 주소 복사」 버튼이 나옵니다
2. 내부망에서 보고서 확인
3. 보고서를 보낸 뒤 목록 화면의 **「이 목록 지우기」** (사진이 있으면 한 번 더 확인합니다)

## 비밀번호를 바꿀 때 (분실·인사이동 등)
**한 팀만 바꿀 때 (보통)**: 앱 배포가 필요 없습니다.
1. 그 팀의 새 비밀번호를 정해 그 팀 사람에게 **구두 또는 내부 메신저로만** 알립니다 (메일 본문에 적지 않음)
2. 이후 목록 파일·QR을 만들 때 새 비밀번호를 넣습니다 (Claude Code로 만들면 `list-passphrase-<팀>.txt` 를 새 비밀번호로 다시 저장)
3. 휴대폰은 새 파일을 처음 열 때 새 비밀번호를 한 번 묻습니다

**모든 팀 키를 한꺼번에 바꿀 때 (드묾)**: Claude Code에 "모든 팀 키 바꿔줘" → 새 솔트 추가 → 앱 다시 배포 → 새 `admin.html` 다시 반입. 휴대폰은 새 파일을 열 때 팀 비밀번호를 한 번 다시 묻습니다.

## 이 방식을 고른 이유

| 방식 | 쓰지 않은 이유 |
|---|---|
| GitHub에 암호화 목록을 올리고 휴대폰이 자동으로 받기 (지시서 2) | 공개 저장소라 누구나 내려받을 수 있고, 지워도 이력에 남음. 기관 정보를 외부 서버에 두는 것 자체가 설득이 어려움 |
| 엑셀 내용을 그대로 GitHub에 올림 | 시설물 주소·연락처·직원 이름이 그대로 공개됨 |
| 외부 클라우드 DB(Firebase 등) | 기관 정보를 외부 서비스에 저장, 계정·보안 검토 부담이 큼 |
| 평문 공유 링크 | 시설 정보가 링크 주소에 그대로 들어감 → 폐지 |
| 암호화 없이 기관 메일로만 전달 | 메일 오발송·전달, 휴대폰 분실 대비로 암호화는 유지 |
