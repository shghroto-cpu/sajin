# Claude Code로 처음 시작하기

## 1. 준비
1. 이 압축파일을 원하는 위치에 풉니다 (예: `문서/sajin-app`)
2. 원본 한글 양식(.hwpx)을 `template/source/` 폴더에 복사해 둡니다 (양식 변경 시에만 필요)
3. Claude Code(데스크톱 앱의 Code 탭 또는 터미널)를 열고 작업 폴더로 `sajin-app`을 선택합니다

## 2. 첫 번째 지시 (그대로 붙여넣기)
> CLAUDE.md를 읽고 이 프로젝트를 파악해 줘.
> 그다음 아래를 순서대로 해줘. 각 단계 결과를 알려주고, 로그인이 필요하면 멈추고 나에게 알려줘.
> 1. 필요한 도구 확인: node, python3, git 버전 확인. 없는 것이 있으면 설치 방법을 알려줘
> 2. `npm install` 후 `npm test` 실행해서 "검사 통과"가 나오는지 확인
> 3. 이 폴더를 내 GitHub 저장소 `sajin`(이미 index.html만 올라가 있음)에 연결해서,
>    기존 index.html을 이 프로젝트 전체로 교체하는 커밋을 올려줘. 커밋 메시지: "소스 구조로 전환"
> 4. 2~3분 뒤 배포 주소가 정상으로 열리는지 확인해 줘

GitHub 로그인(인증)은 처음 한 번 직접 해야 합니다. Claude Code가 안내하는 방법(브라우저 로그인 등)을 따르세요.

## 3. 이후 개선 요청 예시
- "메일로 보내기가 아이폰에서 안 돼. docs/개선과제.md 1번 원인부터 확인해서 고쳐줘"
- "사진 설명 버튼에 '들뜸', '백화' 추가해줘"
- "양식 파일을 새로 바꿨어. template/source에 넣었으니 반영해줘"

수정이 끝나면 Claude Code에게 "테스트하고 배포까지 해줘"라고 하면 `npm test` → `git push`까지 진행합니다.
배포 후에는 **휴대폰에서 새로고침**해서 확인하세요.
