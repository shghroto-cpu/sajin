# 현장 사진대지 (관리주체 합동점검 결과보고서 작성 앱)

휴대폰으로 현장 사진을 찍고 설명을 달면, 국토안전관리원 양식 그대로의 **한글 보고서(.hwpx)**를 만들어 주는 웹앱입니다.

- 사용 주소: `https://<GitHub아이디>.github.io/sajin/` (사파리·크롬으로 열기)
- 사진과 입력 내용은 **각자 휴대폰에만 저장**되며 어디에도 올라가지 않습니다.

## 사용 방법
1. 「기본정보」에 시설물명, 점검기간 등 입력 (나중에 한글에서 고쳐도 됨)
2. 항목별 「사진 촬영·추가」 → 사진을 눌러 설명 입력
3. 「메일로 보내기」 또는 「파일 저장」(zip 안에 한글 보고서 + 사진 폴더)
