# 개발지시서: 사실관계조사 대상목록(엑셀) 연동

> Claude Code에게: 먼저 `CLAUDE.md`를 읽고 이 문서대로 구현해 줘.
> 이 파일은 `docs/엑셀_대상목록_연동_개발지시서.md`에 저장해 두고 (예시 값은 모두 가린 값이므로 공개 저장소에 올려도 됨) 진행 상황을 맨 아래 "작업 기록"에 남겨 줘.
> 담당자는 비개발자다. 끝나면 한국어로 "무엇이 바뀌었는지 / 휴대폰에서 어떻게 확인하는지"를 단계별로 알려줘.

---

## 1. 목적
사실관계조사 출장 전, 담당자가 작성하는 **대상시설물 목록 엑셀**(시설물명·주소·종별·등급·준공일·날짜 등)을 웹앱에 불러와서

1. 시설물별 **기본정보를 자동으로 채우고** (지금은 수기 입력)
2. 출장 대상 시설물을 **앱에 미리 목록으로 등록**해 두고, 현장에서 시설물을 골라 바로 사진을 찍을 수 있게 한다
   (예시 파일 기준 7개 시설, 시설물마다 보고서 1건)

---

## 2. 입력 엑셀 형식 (예시: `사실관계조사_대상시설물_목록.xlsx`)

| 행 | 내용 |
|---|---|
| 1행 | 제목 `붙임1. 사실관계조사 대상시설물 목록(건축)` (A1:L1 병합) |
| 2행 | 비어 있음 (A2:H2 병합) |
| 3행 | **머리글**: 연번, 시설물명, 수신처, 주소, 시설물종류, 종별, 준공일, 용역종류, 등급, 출장자, 날짜(오전,오후), 동수, 연락처, 담당자 |
| 4~10행 | 시설물 7건 |
| 그 외 | P10에 `=SUM(L4:L10)` 같은 계산식, 11행 빈 행 |
| 시트 이름 | `26년 4차 사실관계조사 시설물` → 출장 회차 이름으로 사용 |

예시 1행(4행) 값 (실제 값은 가림):
```
1 | ○○아파트 | ○○아파트 관리사무소 | ○○도 ○○시 ○○구 ○○동 000 | 공동주택 | 2종 |
2001-01-01 | 정밀안전점검 | B | 홍길동, 김철수 | 2026-11-02 (월) | 6 | 000-000-0000 | (담당자 빈칸)
```

### 읽기 규칙 (파일마다 조금씩 다를 수 있으므로 반드시 지킬 것)
- **머리글 행은 위치가 아니라 내용으로 찾는다**: 앞 10행 중 `시설물명` 칸이 있는 행. 열 순서도 머리글 이름으로 찾는다
- 머리글 이름은 공백·줄바꿈·괄호 차이를 무시하고 비교하며, 아래 별칭도 같은 열로 인정한다
  - 시설물명: 시설물명, 시설명 / 수신처: 수신처, 관리주체 / 주소: 주소, 위치, 소재지
  - 종별: 종별, 구분, 종 / 등급: 등급, 안전등급 / 날짜: 날짜, 일자, 출장일, 점검일
- **데이터 행 끝**: `시설물명`이 빈 행이 나오면 멈춘다. 머리글 열 밖의 칸(P열 계산식 등)은 무시한다
- **날짜**: 문자열(`2026-11-02 (월)`, `2026.11.2`, `2026-11-02 오전`)과 엑셀 날짜 숫자(예: 46328) 모두 처리. 요일·오전/오후 표시는 따로 보관
- **연락처·담당자**: 비어 있을 수 있음. 비면 화면에 표시하지 않음
- 첫 번째 시트만 읽되, 머리글을 못 찾으면 다음 시트를 찾는다. 끝까지 못 찾으면 "시설물명 열을 찾지 못했습니다" 안내

## 3. 엑셀 열 → 보고서 항목 매핑

| 엑셀 열 | 앱 항목(`meta`) | 보고서에 들어가는 모양 | 비고 |
|---|---|---|---|
| 시설물명 | `facility` | 시설물명 : ○○아파트 | 파일명에도 사용 |
| 수신처 | `owner` | 관리주체 : ○○아파트 관리사무소 | ※확인 필요 1 |
| 주소 | `location` | 위    치 : ○○도 ○○시 … | |
| 시설물종류 | `kind` | 상세표 종류 칸: 공동주택 | ※확인 필요 2 |
| 종별 | `grade` | 상세표 구분 칸: 2종 | |
| 준공일 | `completed` | 2001.01.01 | `-` → `.` 로 변환 |
| 등급 + 용역종류 | `safety` | B (정밀점검) | 정밀안전점검→정밀점검, 정밀안전진단→정밀진단. ※확인 필요 3 |
| 출장자 | `inspectors` | 총 2명(국토안전관리원 2명) | 쉼표로 인원 계산. 현장에서 시설관리자 인원 입력 시 `총 4명(국토안전관리원 2명, 시설관리자 2명)` |
| 날짜 | `period`, `date` | 점검기간 : 2026. 11. 2. / 표지 : 2026. 11. | |
| 동수 | (목록 화면 표시용) `site.buildings` | 보고서에는 넣지 않음 | |
| 연락처 | (목록 화면 표시용) `site.phone` | 보고서에는 넣지 않음 | 누르면 전화 걸기 |
| 담당자 | (목록 화면 표시용) `site.contact` | 보고서에는 넣지 않음 | |
| 연번 | `site.no` | 목록 순서 | |
| (엑셀에 없음) | 층수, 연면적, 최고높이 | 빈칸 | 현장 또는 한글에서 입력 |

### 확인 필요 사항 (일단 아래 기본값으로 구현하고, 담당자에게 확인 질문을 남길 것)
1. **수신처 = 관리주체**로 넣는다. (수신처가 관리사무소 이름인 경우가 많아 대부분 맞을 것으로 보임)
2. 상세표 **종류 칸에 `공동주택`**을 넣는다. 원본 양식에는 `건축물`이라고 되어 있으므로, 담당자가 원하면 `건축물`로 고정하는 설정을 둔다 (`settings.kindMode`: `excel` | `fixed`)
3. 등급 괄호 안의 **연도**는 엑셀에 없으므로 `B (정밀점검)`까지만 넣는다. 엑셀에 `점검연도`·`최종점검` 같은 열이 추가되면 `B ('25년 정밀점검)` 형식으로 채운다

## 4. 기능 요구사항

### F1. 엑셀 불러오기
- 첫 화면(대상 목록)에 **「엑셀로 대상 목록 불러오기」** 버튼. 파일 선택은 `.xlsx`만
- 불러오기 전 **미리보기**: "26년 4차 사실관계조사 시설물 · 7개 시설" + 시설물명 목록 + 자동으로 채워질 항목 요약 → 「등록」/「취소」
- 읽지 못한 칸이 있으면 미리보기에 노란색으로 표시 (예: "3번 □□아파트: 준공일 형식을 읽지 못함")
- **외부 라이브러리를 새로 추가하지 않는다.** 이미 쓰는 JSZip으로 xlsx(zip)를 열고 `xl/sharedStrings.xml`, `xl/workbook.xml`, `xl/worksheets/sheetN.xml`을 직접 읽는다
  - 새 파일 `src/xlsxreader.js`: 브라우저와 Node 모두에서 돌도록 DOMParser 없이 작성(정규식 기반으로 충분: `<c r="B4" t="s"><v>12</v></c>` 형태). 공유 문자열(t="s"), 인라인 문자열(t="inlineStr"), 숫자, 수식 결과(`<f>` 무시하고 `<v>` 사용) 처리
  - 새 파일 `src/importer.js`: 행 → `site` 변환(3장 매핑), 순수 함수로 작성해 테스트 가능하게

### F2. 대상 목록 화면 (새 첫 화면)
- 상단: 출장 회차 이름(시트 이름), 등록 시설 수
- **날짜별로 묶은 카드 목록** (예: 11.2(월) 2곳 / 11.3(화) 3곳 / 11.4(수) 2곳). 오늘 날짜 묶음을 맨 위로, 오늘이 아니면 날짜순
- 카드 내용: 연번, 시설물명, 종별·등급, 동수, 주소, 진행상태(사진 0장 → "사진 n장" → "저장함"), 연락처가 있으면 「전화」 버튼(`tel:` 링크)
- 카드를 누르면 → 지금의 작성 화면이 **그 시설물의 보고서**로 열림. 기본정보는 이미 채워져 있음. 상단에 「← 목록」
- 목록이 비어 있으면 지금처럼 「직접 입력해서 시작」도 가능 (엑셀 없이 쓰는 경우)
- 「목록 비우기」: 확인 후 해당 회차의 시설물·사진 전부 삭제

### F3. 시설물별 보고서 분리 저장 (데이터 구조 변경)
지금은 보고서 1건(`draft`)만 저장한다. 시설물마다 따로 저장하도록 바꾼다.

```js
// IndexedDB 'kv' 저장소, 키 'appState'
{
  v: 3,
  batch: { name: '26년 4차 사실관계조사 시설물', importedAt: '2026-10-28T09:00:00' } | null,
  activeId: 'site_xxx' | null,          // 지금 열려 있는 시설물
  settings: { kindMode: 'excel', crop: true, withPhotos: true, attach1: true },
  sites: [{
    id, no, buildings, phone, contact, travelers: ['홍길동','김철수'], dateLabel: '2026-11-02 (월)',
    savedAt: null,                       // 마지막 파일 저장/메일 시각 → 진행상태 표시
    edited: ['owner'],                   // 사용자가 직접 고친 meta 항목 (재불러오기 시 보호)
    meta: { ... 지금의 meta와 동일 ... },
    sections: [ ... 지금과 동일 ... ]
  }]
}
// 사진은 지금처럼 'photos' 저장소에 사진 id로 저장 (시설물 간 공유 없음)
```
- **기존 사용자 자료 옮기기(마이그레이션)**: 예전 `draft`(v2)가 있으면 시설물 1건으로 옮기고 사진도 그대로 연결. 옮긴 뒤 `draft` 삭제. 옮기다 실패해도 예전 자료를 지우지 말 것
- 「새로 시작」 버튼은 "이 시설물 보고서 비우기"로 의미를 바꾼다 (목록의 다른 시설물에는 영향 없음)
- 파일명: `YYMMDD_관리주체_합동점검_결과_보고서(시설물명).hwpx` — YYMMDD는 **엑셀의 점검 날짜** 기준 (없으면 오늘)

### F4. 미리 등록 · 실원과 목록 공유
출장 전에 사무실에서 목록을 만들고, 함께 가는 실원 휴대폰에도 같은 목록이 등록되게 한다.
1. **휴대폰에서 직접 불러오기**: 엑셀 파일을 메일·메신저로 휴대폰에 받아 F1로 불러오기
2. **목록 공유 링크** (권장): 목록 화면의 「목록 공유 링크 만들기」 → 링크를 복사해 메신저로 전달 → 받은 사람이 누르면 미리보기 후 등록
   - 목록 정보를 압축(JSON → deflate(JSZip 또는 `CompressionStream`) → base64url)해서 **주소의 `#` 뒤**에 넣는다: `https://<아이디>.github.io/sajin/#list=...`
   - `#` 뒤 내용은 GitHub 서버로 전송되지 않는다. 사진·작성 내용은 넣지 않고 **엑셀에서 온 정보만** 넣는다
   - 「연락처·담당자 포함」 체크(기본 해제). 출장자 이름도 체크 해제 시 제외
   - 링크로 등록이 끝나면 `history.replaceState`로 주소의 `#list=` 부분을 지운다
   - 링크가 너무 길면(약 6,000자 초과) "목록 파일로 공유하세요" 안내 후 3번으로
3. **목록 파일 내보내기/불러오기**: `대상목록_26년4차.json` 저장·불러오기 (링크가 안 될 때 대비)

### F5. 다시 불러오기 (목록이 바뀐 경우)
같은 회차 엑셀을 다시 불러오면 선택지를 준다.
- 「바뀐 내용만 반영」(기본): **시설물명 + 날짜**가 같은 시설물은 유지하면서 엑셀 값으로 갱신. 단 `edited`에 있는 항목(현장에서 직접 고친 값)은 덮어쓰지 않음. 새 시설물은 추가, 엑셀에서 빠진 시설물은 "목록에서 빠짐" 표시만 하고 지우지 않음(사진 보호)
- 「전부 새로 등록」: 확인 후 기존 회차를 지우고 새로 등록

### F6. 현장 편의 (선택 — 시간 여유가 있으면)
- 카드의 주소 옆 「지도」 버튼: 네이버지도/카카오맵 검색 주소로 이동 (주소가 지도 서비스로 전송되므로 **누를 때만** 이동, 자동 전송 금지)
- 현장에서 「시설관리자 인원」 숫자 입력 칸 → 점검자 문구 자동 완성

## 6. 보안 · 개인정보 (반드시 지킬 것)
- **이 저장소는 공개(Public)다. 실제 대상목록 엑셀은 절대 커밋하지 않는다.**
  - `.gitignore`에 `*.xlsx` 추가, 테스트용 가짜 파일만 예외: `!tests/fixtures/sample_list.xlsx`
  - 실제 시설물명·주소·전화번호·직원 이름을 코드 기본값, 테스트, 문서 예시에 넣지 않는다 (이 문서의 예시 값도 코드에 복사 금지)
- 엑셀 내용은 휴대폰 브라우저(IndexedDB)에만 저장. 서버 전송·외부 API 호출 금지 (F6 지도 버튼의 사용자가 누를 때만 이동하는 것은 예외)
- 목록 공유 링크는 `#` 뒤에만 정보를 넣는다. 쿼리(`?`)에 넣지 않는다
- 「목록 비우기」, 「이 시설물 보고서 비우기」로 휴대폰에서 완전히 지울 수 있어야 한다
