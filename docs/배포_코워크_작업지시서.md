# 현장 사진대지 앱 GitHub Pages 배포 작업지시서 (Claude Cowork용)

## 1. 작업 목적
휴대폰용 「현장 사진대지」 웹앱(`index.html` 파일 1개)을 GitHub Pages에 올려,
실원들이 **앱 설치·로그인 없이 링크(사파리·크롬)만으로** 사용할 수 있는 공개 주소를 만든다.

- 최종 결과물: `https://<GitHub아이디>.github.io/sajin/` 형태의 주소 1개
- 앱 특성: 사진·입력 내용은 사용자 휴대폰에만 저장되며 서버로 전송되지 않음 (페이지에는 보고서 양식 틀만 포함)

---

## 2. 사람이 먼저 해둘 일 (Cowork가 대신하지 않음)
Cowork는 계정 생성이나 비밀번호 입력을 하지 않는다. 아래는 직접 준비한다.

1. **GitHub 계정**: github.com 가입 후, Chrome에서 **로그인된 상태**로 둔다
2. **파일 위치**: Claude에서 받은 `index.html`을 Cowork 작업 폴더에 둔다
   - 예: `작업폴더/현장사진대지/index.html`
3. **보안 확인**: 정보보안 담당자에게 외부 공개 주소 사용 여부를 확인받는다

---

## 3. Cowork에 붙여넣을 작업 지시 (이 부분을 그대로 전달)

> 아래 순서대로 GitHub Pages 배포를 진행해 줘. Chrome은 이미 GitHub에 로그인되어 있어.
> 각 단계가 끝날 때마다 확인 기준을 점검하고, 막히면 멈추고 화면 상황을 알려줘.
>
> **입력 파일**: `현장사진대지/index.html` (파일 내용은 절대 수정하지 말 것)
> **저장소 이름**: `sajin` (이미 있으면 진행하지 말고 나에게 물어볼 것)
>
> **1단계 — 로그인 확인**
> - github.com 접속 → 오른쪽 위에 프로필 사진이 보이는지 확인
> - 로그인 화면이 나오면 멈추고 "로그인이 필요합니다"라고 알려줄 것 (비밀번호 입력 금지)
> - 확인한 GitHub 아이디를 기록
>
> **2단계 — 저장소 만들기**
> - 오른쪽 위 `+` → `New repository`
> - Repository name: `sajin`
> - 공개 범위: **Public** (무료 Pages는 Public 필요)
> - 다른 옵션(README, .gitignore, license)은 모두 체크하지 않음
> - `Create repository` 클릭 전에 위 설정을 나에게 보여주고 승인받을 것
> - ✅ 확인: 주소창이 `github.com/<아이디>/sajin` 이고 빈 저장소 안내 화면이 보임
>
> **3단계 — index.html 업로드**
> - 빈 저장소 화면의 `uploading an existing file` 링크 클릭
> - `현장사진대지/index.html` 파일을 업로드 (파일 크기 약 3MB)
> - Commit message: `현장 사진대지 앱 배포`
> - `Commit changes` 클릭
> - ✅ 확인: 저장소 파일 목록에 `index.html` 1개가 보임
>
> **4단계 — GitHub Pages 켜기**
> - 저장소 상단 `Settings` → 왼쪽 메뉴 `Pages`
> - Build and deployment → Source: `Deploy from a branch`
> - Branch: `main`, 폴더: `/ (root)` 선택 → `Save`
> - ✅ 확인: 화면 상단에 사이트 주소 안내(또는 배포 진행 중 표시)가 나타남
>
> **5단계 — 배포 확인**
> - 2분 기다린 뒤 `https://<아이디>.github.io/sajin/` 접속
> - 404가 나오면 2분 간격으로 최대 5회 새로고침
> - ✅ 확인: 남색 상단 바에 "현장 사진대지" 제목과 노란 줄무늬, 아래쪽에 「메일로 보내기」 노란 버튼이 보임
>
> **6단계 — 결과 보고**
> 아래 형식으로 정리해 줘.
> ```
> 배포 주소: https://<아이디>.github.io/sajin/
> 저장소 주소: https://github.com/<아이디>/sajin
> 배포 완료 시각:
> 확인 결과: (화면 정상 표시 여부)
> 특이사항:
> ```

## 4. Cowork가 하지 말아야 할 것
- GitHub 계정 생성, 비밀번호·인증코드 입력
- `index.html` 파일 내용 수정, 다른 파일 추가
- 기존 다른 저장소 수정·삭제
- 저장소를 Private으로 변경 (Pages가 꺼짐)
- 결제·유료 플랜 관련 화면 진행

---

## 5. 앱을 수정해서 다시 배포할 때 (업데이트 지시)

> GitHub 저장소 `sajin`의 `index.html`을 새 파일로 교체해 줘.
> 1. `github.com/<아이디>/sajin` 접속 → `Add file` → `Upload files`
> 2. 새 `현장사진대지/index.html` 업로드 (같은 이름이라 자동으로 덮어씀)
> 3. Commit message: `앱 수정 반영 (YYYY-MM-DD)` → `Commit changes`
> 4. 3분 뒤 배포 주소에 접속해 화면이 정상인지 확인하고 결과 보고

- 주소는 바뀌지 않으므로 실원들에게 다시 보낼 필요 없음
- 실원 휴대폰에 이전 화면이 보이면 새로고침 안내

---

## 6. 문제 해결
| 증상 | 조치 |
|---|---|
| `sajin` 이름이 이미 있음 | 작업 중단 후 담당자에게 확인 (기존 저장소 덮어쓰기 금지) |
| 5단계에서 계속 404 | Settings › Pages에서 Branch가 `main` / `/ (root)`인지 재확인 후 10분 대기 |
| 업로드 버튼이 안 보임 | 저장소 첫 화면 `Add file` → `Upload files` 이용 |
| 화면은 뜨는데 디자인이 깨짐 | 업로드한 파일이 `index.html`인지, 크기가 약 3MB인지 확인 |

---

## 7. 배포 후 사람이 할 일
1. **휴대폰 실사용 테스트** (Cowork 불가)
   - 사파리(갤럭시는 크롬)로 배포 주소 열기
   - 사진 2장 추가 → 「메일로 보내기」 → 공유창에서 메일 선택 → 첨부 확인
   - 받은 `.hwpx`를 PC 한글에서 열어 양식 확인
2. **실원 배포 안내 문구**
   > 현장 사진대지 앱 주소입니다: https://<아이디>.github.io/sajin/
   > 카카오톡·네이버 안에서 열지 말고 **사파리(갤럭시는 크롬)**로 열어 주세요.
   > 자주 쓰시면 브라우저 메뉴에서 「홈 화면에 추가」를 해두시면 앱처럼 쓸 수 있습니다.
